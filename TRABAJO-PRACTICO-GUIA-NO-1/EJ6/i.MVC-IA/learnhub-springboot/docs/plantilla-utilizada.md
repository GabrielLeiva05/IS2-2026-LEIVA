# Plantilla visual utilizada

Se conserva la estructura visual de la plantilla LearnHub recibida en el ZIP original: imágenes, SCSS/CSS, favicon y recursos estáticos.

Se reemplazó la lógica de cursos de demostración por navegación y vistas Thymeleaf del dominio del diagrama: Profesor, Grado, Aula, Alumno, Materia y Nota.

La plantilla funciona como capa de presentación; el backend no depende de ella para sus reglas de negocio.
